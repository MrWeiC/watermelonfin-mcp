WatermelonFin Upload

Only new files can be imported. No delete, overwrite, or arbitrary destination API is provided.

This native plugin shares Jellyfin's operating-system permissions. It is not a separate filesystem sandbox.

Use a non-administrator Jellyfin user with all content-deletion permissions disabled. Empty list denies everyone.
Fields: Id, Name, Kind. Kind is movies, tv, or other. No filesystem paths are accepted.

Library source paths

Add each Imported target path to the intended Jellyfin library through Dashboard → Libraries. Never add the Staging directory.
